3. Lookups

// modern, use this by default
=XLOOKUP(lookup, lookup_range, return_range, "not found", 0)

// classic and works everywhere

// legacy: can only look right, breaks if you insert columns
=VLOOKUP(lookup, table, col_number, FALSE)

Conditional aggregation

=COUNTIFS(sex_rng,"F", age_rng,">=65")
=SUMIFS(value_rng, sex_rng,"F", date_rng,">="&DATE(2026,1,1))
=AVERAGEIFS(value_rng, group_rng, E2)
=MAXIFS(…)   =MINIFS(…)
In SUMIFS the sum range comes first; in SUMIF it comes last. Criteria with operators are text: ">=65", or ">="&F1 for a cell value.

5. Dynamic arrays (365 / 2021+)

One formula, many results. The result "spills" into neighbouring cells.

=FILTER(A2:D100, (D2:D100="F")*(B2:B100>=65), "none")
=SORT(A2:D100, 2, -1)            // by column 2, descending
=UNIQUE(D2:D100)
=SORTBY(A2:A100, B2:B100, -1)
=XLOOKUP(…)  // can return whole rows
=SEQUENCE(10)   =TEXTSPLIT(A2,",")
=TAKE(rng,5)  =DROP(rng,1)  =VSTACK(r1,r2)

LET: name things inside a formula

=LET(
  pts, FILTER(B2:B100, D2:D100="F"),
  AVERAGE(pts) / STDEV.S(pts)
)
#SPILL! means something is blocking the spill area. Clear the cells below/right of the formula.

  • Right-click a value › Show Values As for % of total, % of row, running total.
  • Group dates into months/years and numbers into bins (right-click a row label).
  • Source should be a clean table: one header row, no blanks, no merged cells. Use Ctrl+T first so the pivot grows with data.
  • Pivots do not refresh themselves. Right-click › Refresh, or Alt+F5.

=TRIM(A2)  =CLEAN(A2)  =UPPER/LOWER/PROPER

=TEXT(A2,"yyyy-mm-dd")

Dates are numbers

=TODAY()  =NOW()  =DATE(2026,11,16)
=YEAR/MONTH/DAY(A2)
=DATEDIF(A2, TODAY(), "Y")       // age in years
=EOMONTH(A2, 0)   =EDATE(A2, 3)
=NETWORKDAYS(start, end)
If a "date" is left-aligned, it's text. Fix with DATEVALUE or Text to Columns. Day-month order depends on your regional settings, so import dates from other countries with care.

11. Excel vs Google Sheets: the major differences

Both are moving targets, so check feature availability in your own version. Where a row says "both", syntax is mostly the same.

AreaExcel (desktop, 365)Google Sheets
CollaborationCo-authoring works when the file lives on OneDrive/SharePoint. Desktop-first.Built for it. Real-time editing, comments, version history, and sharing links are the default.
Size & speedHandles large data. Up to 1,048,576 rows × 16,384 columns per sheet. Runs locally, so it is fast on big files.Cell cap. About 10 million cells per spreadsheet. Browser-based, so it slows down with heavy formulas and large imports.
Data transformationPower Query (visual ETL, recorded steps) and Power Pivot (data model, DAX, millions of rows).No equivalent. Use QUERY() (SQL-like), FILTER, IMPORTRANGE, plus Apps Script for heavy lifting.
PivotTablesMore powerful: slicers, timelines, grouping, calculated fields, data model, PivotCharts.Simpler pivots that are quick to build. Fewer options. Slicers exist for tables and charts.
FormulasMost functions in both. Dynamic arrays spill automatically.
Excel-only: TEXTSPLIT, VSTACK/TAKE family on current builds, CUBE*, many stats and financial extras.		Sheets-only: QUERY, IMPORTRANGE, IMPORTHTML/IMPORTXML, GOOGLEFINANCE, GOOGLETRANSLATE, SPARKLINE.
Arrays need ARRAYFORMULA() in many cases.
AutomationVBA macros (desktop only), Office Scripts (web), Power Automate.Apps Script (JavaScript). Runs in the cloud, triggers on schedule or on edit, and is good for connecting Google services.
Charts & formattingRicher: more chart types, deeper formatting, conditional formatting rules, themes, templates.Cleaner but more limited. Fewer chart types and less control over details.
Data types / tablesExcel Tables (Table1[col]), stock and geography data types.Tables exist but the structured-reference style is lighter. Smart chips for people, files, dates.
Files & access.xlsx on your computer or cloud. Works offline by default. Share by file or link.Lives in Drive. Works offline only if enabled. Opens .xlsx and exports to it, but advanced features can be lost on conversion.
CostPaid (Microsoft 365 or one-time license). Excel for the web is free but limited.Free with a Google account. Workspace plans add admin controls.
ShortcutsWindows and Mac sets, long-standing muscle memory.Similar but not identical. Some Excel shortcuts (e.g. F4 for $) work, others differ.

Translating common formulas

TaskExcelGoogle Sheets
Apply to a whole column=A2:A100*2 (spills)=ARRAYFORMULA(A2:A100*2)
SQL-style queryPower Query, or FILTER + SORT=QUERY(A1:D100,"select A,sum(C) where D='F' group by A")
Pull from another fileExternal link or Power Query=IMPORTRANGE("url","Sheet1!A1:D")
Split text=TEXTSPLIT(A2,",")=SPLIT(A2,",")

Rule of thumb: Excel for large datasets, heavy analysis, Power Query/Pivot work and offline use. Sheets for sharing, live collaboration, lightweight tracking and pulling in web or Google data. If your data is clinical or sensitive, the deciding factor is often where the file is allowed to live, not the features.
